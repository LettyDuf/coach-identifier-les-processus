# Coach Processus

Outil pédagogique pour apprendre à repérer les processus d'un groupe de
travail, à les classer (type et niveau), et à concevoir leur mesure
(chaîne KBI → KPI → KGI).

## ▶ Ouvrir l'outil

[**Lancer Coach Processus**](https://lettyduf.github.io/coach-identifier-les-processus/coach-processus.html)

(nécessite que GitHub Pages soit activé sur ce dépôt : Settings → Pages →
Deploy from a branch → main → /)

## Développement

```bash
npm install
npm run dev      # serveur de développement
npm test         # suite de tests
npm run build    # build monofichier -> coach-processus.html
```

Voir `ROADMAP.md`, `DOMAINE.md` et `DECISIONS.md` pour le contexte et les
choix du projet.
